# Day 03 Polygons · tutorial data

| File | What's inside | Source |
|---|---|---|
| `uzbekistan_regions.geojson` | 14 polygons: 12 regions, Karakalpakstan and Tashkent City. Column `region`. | [simplemaps.com](https://simplemaps.com), via `Boundaries/uz.shp` in this repository, with names that tell Tashkent City and Tashkent Region apart. |
| `population_2026.csv` | Permanent population on 1 January 2026, in people. Columns `region`, `population`. Total: 38,236,700. | [Statistics Agency of Uzbekistan](https://stat.uz/en/press-center/news-of-committee/66574-zbekiston-a-olisi-38-2-mlndan-oshdi-4), published in thousands (e.g. 4,379.8 thousand → 4379800). |
| `day03_polygons_data.zip` | Both files and this README. | |

The national total published by stat.uz is 38,236,704. The regional figures are rounded to the nearest 100 people, so the CSV adds up to 38,236,700.
