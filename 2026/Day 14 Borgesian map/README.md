# Day 14: Borgesian map

**Date:** 14 November 2026

## Theme
A map so detailed it becomes the territory. Inspired by Borges' [On Exactitude in Science](https://en.wikipedia.org/wiki/On_Exactitude_in_Science).

A map so detailed it becomes the territory?
